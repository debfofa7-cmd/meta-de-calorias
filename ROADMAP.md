# Roadmap e milestones

MVP (sprints de 2 semanas)
Sprint 1:
- Protótipo UI (telas: onboarding, dashboard, photo analyze, meal editor)
- Modelagem Firestore
Sprint 2:
- Cloud Functions + Vision + OpenAI básico
- Importar nutrition DB
Sprint 3:
- Integração Flutter: captura imagem, edição, salvar refeição
- Water tracker, weight logging, gráficos simples
Sprint 4:
- Chat IA (perguntas do usuário), notificações, ajustes de heurística, testes

Extras pós-MVP:
- Treinos personalizados
- Comparação de fotos com métricas de volume (ML)
- Treinamento de modelo customizado para incremento de precisão
